### Findings

1. **Bug (fixed here):** gtag.js sends the first `page_view` as soon as it reads `gtag('js')`. The site set the
   `style_variant` user property after that, so the look only rode on the visitor's next hit; one-page visitors had no
   look, which skews the A/B test's visitors per look. `src/components/Analytics.astro` now sets it before `gtag('js')`.
   `page_view` still carries no *event* parameter `style_variant` (no call order gives it one): A/B reports use the
   user-scoped dimension for visitors, the event parameter on `book_click` / `booking_submitted` for conversions.
2. **Added:** `booking_submitted` carries `via` (`whatsapp`, `sms`, `copy`), taken from PR #35.
3. **"booking_submitted is missing" (reported by the owner): not a bug.** Runs 4–6: the phone had "Necessary only"
   saved. Also, GA4 Admin → Events → Recent events still did not list `booking_submitted` after Realtime had counted it;
   that list lags by hours. Check with Reports → Realtime.
4. **PR #35's `book_click` fix is not needed.** PR #35 found `book_click` lost when the Book link opens /book/ in the
   same tab (its headless check, which reads hits through CDP). In real browsers it arrives: run 4 (desktop Chrome) and
   run 6 (Android Chrome) both show `book_click` in Realtime after the page changed. PR #35 is closed without that change.
5. **Why the SMS tap is checked by hand.** gtag holds a hit about 5 s before sending, and only sends at once when the
   page actually unloads (`pagehide`), not when it is hidden or with `event_callback` / `transport_type: 'beacon'`
   (scratch measurement below). A headless browser cannot switch to the Messages app, so the script cancels the SMS tap
   and the app switch was tested on a real phone (run 6). iPhone Safari, which may suspend a hidden page sooner, is
   not checked.

### GA4 admin, as read in the browser (18:30–18:55 AEDT)

- Data retention: event data 14 months, user data 14 months.
- Custom dimensions: `Style variant event` (event, `style_variant`), `Style variant user` (user, `style_variant`).
- Channel group `Channels incl. AI`: `AI assistants` 15th, `Referral` 16th; condition Source **partially matches regex**
  (GA4's "matches regex" must match the whole value, so it would miss e.g. `www.perplexity.ai`).
- Key events: `book_click`, `booking_submitted`, `message_click`, `map_click` (the last three added 18:50 AEDT through
  Events → Create event → **Create with code** → Mark as key event → **Don't set a default key event value**, so GA
  uses the AUD value the site sends; "Create without code" would make a derived event from page views).
