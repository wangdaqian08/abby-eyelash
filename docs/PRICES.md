# 价格表使用说明（给 Abby）

网站上所有服务的**价格和时长**都来自一张表：[`src/data/prices.csv`](../src/data/prices.csv)。改了这张表并提交后，网站会自动重新生成，价格表、首页卡片、预约页、Google 和 AI 读取的数据会一起更新。

## 怎么改

**在 GitHub 网页上改**（最简单）
1. 打开 `src/data/prices.csv`，点右上角的铅笔图标（Edit）。
2. 修改“价格”“时长（分钟）”和“更新日期”这三列。
3. 点 **Commit changes** 保存。几分钟后网站就会更新。

**用 Numbers 或 Excel 改**
- 改完后保存为 CSV 格式（UTF-8），再上传覆盖原文件。

## 每一列怎么填

| 列 | 怎么填 | 能不能改 |
|---|---|---|
| 编号 | 系统用的，例如 `lash-lift/lift-tint` | ❌ 不要改 |
| 服务、项目 | 只是方便阅读，网站上显示的名称不受这两列影响 | 改了也不会生效 |
| 价格 | 见下面的写法 | ✅ |
| 时长（分钟） | 整个服务大约多少分钟，**包括准备和收尾**。预约系统按这个时长空出时间 | ✅ |
| 更新日期 | 改了这一行的价格或时长，就把日期改成当天，例如 `2026-11-05`。网站会显示“价格更新于”这一天 | ✅ |
| 备注 | 随便写，网站不显示 | ✅ |

**价格的四种写法**

| 写法 | 网站显示 | 例子 |
|---|---|---|
| `80` | $80 | 固定价格 |
| `130起` | $130 起 | 起价 |
| `10-20` | $10 起，正文里写 $10–$20 | 价格区间 |
| `50%` | 按这个服务最便宜的全套价计算 | 睫毛回补：50% × $80 = $40 起 |

## 填错了怎么办

如果有一行填错（比如价格写成“八十”，或者日期格式不对），网站**不会更新**，会继续显示之前的价格。同时会显示哪一行、哪一列有问题，例如：

> 第 13 行（lash-lift/lift-tint）：价格“八十”看不懂，请写成 80、130起、10-20 或 50%

按提示改好再提交就行。

## 这张表管不到的

- 新增或删除服务项目、修改项目名称（包括英文名）、修改服务介绍：这些需要开发者改代码。
- 只改价格和时长，不需要找开发者。
