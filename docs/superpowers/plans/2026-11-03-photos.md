# Abby's Real Photos Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the stock placeholders with Abby's own lash and nail photos: a "lash looks" card section on the home page, a colour-grouped nail section with one video, and real photos on the service pages, all at uniform sizes and without hurting SEO/GEO.

**Architecture:** One typed manifest (`src/data/photos.ts`) is the single source of truth: every photo's id, source file, crop and EN/ZH alt, plus which photo goes where (lash cards, nail groups, styled looks, service slots). A one-off Node script crops the originals into committed masters under `src/assets/photos/`. Astro components read the manifest and render masters with `astro:assets` `<Picture>` (AVIF/WebP, responsive). Prices always come from the existing `services.ts` data.

**Tech Stack:** Astro 7, Tailwind 4, `astro:assets`, sharp 0.35 (already in node_modules via Astro), Node 25 `node --test` (runs `.ts` directly), ffmpeg (local tool, video only).

**Spec:** `docs/superpowers/specs/2026-11-03-photos-design.md` (Chinese). Read it alongside this plan; section numbers below (§4.1…) refer to it.

## Global Constraints

- No new dependencies (spec §5).
- Ratios: lash cards and styled looks 4:3; nail photos 3:4; service-page slots keep their current classes (hero `aspect-[4/3] lg:aspect-[4/5]`, detail `aspect-[3/2] lg:aspect-[4/5]`); only the lash-lift before/after pair keeps its original ratio (§4.4).
- Every photo has non-empty EN and ZH alt that describes style and colour; names, prices and style names are HTML text, never baked into images (§4.4).
- Only the home hero and service-page hero load eagerly; everything else `loading="lazy"`; every `<img>` has width/height (via `<Picture>`).
- Only `角蛋白-翘睫1` and `角蛋白-翘睫3` are before/after (top = before, bottom = after). Never label `造型款-漫画`, `造型款-眼线加浓+下睫毛`, `造型款+下睫毛` as before/after; use their top half (§3).
- Crops keep every nail and eye whole; a watermark is either fully kept or fully cropped out, never half (§3, §4.4). `IMG_2473` must lose its "$180".
- The nail section's only booking link is a small text link "约美甲 →" / "Book nails →"; the most prominent buttons on the page stay lash booking (§2 anti-goals).
- JSON-LD stays as is; no rating/review/FAQ schema (GEO-STRATEGY #11).
- EN and ZH pages have the same structure; check 375px first.
- Silk-ui rules apply: tonal surfaces not dark borders, `tabular-nums` on prices, collapse via `grid-template-rows: 0fr → 1fr`, everything off under `prefers-reduced-motion: reduce`.

## Review Focus

1. **No JavaScript (crawlers, AI fetchers):** all 22 nail photos and all section text must be visible; the "show all" collapse applies only when `<html>` has the existing `.js` class. Pinned in Task 4 Step 6.

3. **Chinese pages:** card links must be `/zh/book?...`, alts and group names Chinese. Pinned in Task 2 Step 1 (`lashLooks('zh')`).
4. **Slow network / video fails:** the video box keeps its 3:4 size with a poster, `preload="none"`, so nothing jumps. Pinned in Task 4 Step 6.

```ts
import type { Lang } from './services';
type L10n = Record<Lang, string>;
export type Ratio = '4:3' | '3:4' | 'original';
/** Fractions of the (EXIF-rotated) source, applied before the ratio crop. */
export interface Box { left: number; top: number; width: number; height: number }
export interface Photo {
  id: string;            // ASCII, e.g. 'classic-natural', 'nail-6920'; master = src/assets/photos/<dir>/<id>.jpg
  dir: 'lash' | 'nails';
  source: string;        // file name inside the source dir, e.g. '单根自然.jpg', 'nails/IMG_6920.JPG'
  ratio: Ratio;
  box?: Box;             // pre-crop (top-half splits, $180 removal)
  position?: 'centre' | 'top' | 'bottom' | 'left' | 'right'; // sharp cover position, default 'centre'
  alt: L10n;
}
export const photos: Photo[];
export const photo: (id: string) => Photo;   // throws `unknown photo <id>`
export const lashCards: { serviceId: string; optionId: string; photo: string }[];
export const nailVideo: { src: string; poster: string /* photo id */; alt: L10n };
export const nailGroups: { id: string; name: L10n; swatch: string /* CSS colour */; items: string[] /* photo ids or 'video' */ }[];

export const styledLooks: { photo: string; name: L10n }[];
export const servicePhotos: Record<string, { hero?: string; detail?: string; beforeAfter?: [string, string] }>;
export const homeHero: string; // photo id
```
